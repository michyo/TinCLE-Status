Scope: TinCLE 3D addon / 32-bit Windows setup

Observation: The Rev.6 package documents that its prebuilt Windows DLL and
linking libraries are 64-bit. A 32-bit TinCLE environment therefore needs to
rebuild the addon and supply matching 32-bit dependency libraries before a
game can use it. The provided sources and symbol checker made this possible.

Suggestion: Ship separately labelled x86 and x64 runtime DLLs, or add a build
helper that reads info.txt, selects matching dependencies, and reports a clear
architecture mismatch before invoking the linker.

■■■■■■■■■■ 操作メモ
- 起動: ■■■■■■■■■■.exe。W/S で前後、A/D で左右へ移動し、Q/E で視点を回転する。
- マウスで各ボタンや立体の仕掛けを選ぶ。Enter または目の絵で装置を調べ、チェックの絵で確定する。
- 仕掛けを拡大している時も、W/A/S/D または Q/E を押すと探索画面に戻って移動・回転できる。操作途中の仕掛けは保存される。
- 画面上部の操作欄は通常は隠れる。マウスを上端へ動かすと表示し、Tab で表示の固定・解除を切り替えられる。
- 仕掛けの手がかりは、対応する仕掛けとは別の部屋に置かれている。台の上の紙や本を見つけてクリックすると読める。
  本の絵または H で手帳を開く。見つける前は空欄で、手帳の左右矢印で発見済みのメモを読み返せる。
- 仕掛けのそばの点は、各つまみの現在の位置を示す。答えを示す図ではない。
- フロッピーディスクの絵 / F5 は手動保存、フォルダの絵 / F9 は手動読込。自動保存もある。
- 謎が解けると印と効果音が出る。誤った操作には短い×印が出る。
- 各区画には横３室・奥２列の部屋があり、前後左右の廊下を歩いて分岐できる。
  本の隣の上下矢印は奥・手前の部屋へ移るマウス操作。地図では訪れた部屋だけを選んで移動できる。
  行けない通路は扉が閉じる。区画の６つの謎を解くと階段の先へ進め、上階や地下に移る。
- 未解放の扉は、同じ区画内で遠くから見ても閉じた状態で表示される。
- 歯車の絵から 8bit-n / 8bit-m / 8bit-p / real の表示を選べる。設定は次回起動時も保持する。
  8bit の各表示は城と画面部品の両方に色とドットの処理が入り、real はドット化・減色を外して色調と陰影を整える。
  real は GRIMCLUTCH の動画を参考に、暖色の石材、石や金属の表面の光沢、暖かい灯りと青みのある暗部を加えている。
  real は既存のモデル・テクスチャ・影を画面解像度 960×540 で表示する方式で、PS5 実機の描画を再現するものではない。
- タイトルの＋印は最初から、フォルダの絵は続き。既存データがある場合、最初からは二回押して確定。
- 確認文、手帳の文章、ボタン内の文字とエンディングは、それぞれの枠の中央に表示する。
- 読み込み時は保存された部屋の開始位置に戻る。訪問した部屋、解決状況、見つけた紙、各部屋で操作途中の仕掛けを保存する。
  以前のセーブも読み込める。旧セーブでは解決済みの部屋の手がかりを発見済みとして引き継ぐ。
- 8bit-m は MSX1 の固定色と色を並べる表現を参考にした見た目で、実機の画面制限を完全に再現したものではない。
  参考: https://note.com/harayoki/n/n834e4dc2e9b1
- 左右の通路が開いて見える従来版: ■■■■■■■■■■.exe（セーブは更新版と別）。

04のデバッグメモ
- シナリオ、仕掛けデータ、判定、3D描画、入力の順にソースを追跡。
- 光路のメモと鏡の正解が一致せず、鏡の２状態と画面上の並びも分かりにくかったため修正。
- 既存の正解とセーブは引き継ぐ。鏡は画面の左から順に調べ、鏡そのものが回転して現在の向きを示す。

makeloop を使った検証メモ
- makeloop 0.12.0 を Codex のプラグインとして導入・有効化。手順に沿って、調査・修正・検証を繰り返した。
- 鏡の別の仕掛けも鏡自体が回転するよう修正し、その手がかりに向きを絞り込める情報を追加した。
- 仕掛けの左右の並び、ソナーの左右、配管の向きと回転を、画面上の見た目と内部の判定で一致させた。
- 独立したテスト用セーブで、30問の手がかりの取得・操作・判定・保存と３種類のエンディングを検証。
- 3Dモデルの変換と Bforartists のプレビューでも鏡の回転と管の接続を確認。元の自動・手動セーブは保持した。

- 鏡の仕掛けでは、上に並ぶ４枚の鏡の面を直接クリックして回す。下にあった重複の鏡は表示しない。
- A/D は視点に対して左右へ移動し、Q/E は左右へ回転する。左右の矢印も視点に合わせて移動する。
- 最初から始めると城門へ続く桟橋に立つ。W で門を通るか、上矢印を押して城内へ進む。入口でのセーブも再開できる。
- 門越しに見えるのは実際の最初の部屋で、徒歩なら城の外と中を行き来できる。
